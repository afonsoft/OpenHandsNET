## Decisões

- API real difere do briefing da issue: severidades são
  critical|important|suggestion|nit (não bug|security|perf — essas são
  kinds); status de finding = open|fixed|dismissed|stale; PATCH só
  aceita open|dismissed (sem "reviewed" — esse é o modelo de scans).
- Duas páginas seguindo o padrão SPEC-143 (ScansPage/ScanDetailPage):
  /reviews lista runs (filtros server-side repository/pr/status +
  cursor page_id) e /reviews/{id} detalha com findings agrupados por
  arquivo + filtros client-side (severity/status/stale-only toggle).
- Link provider = comment_url do finding (permalink do review postado,
  e.g. github.com/o/r/pull/42#pullrequestreview-N) — o record do run
  não expõe pr_url nem summary text (limitação documentada no PR).
- Emoji de severidade reusa os do ReviewFormatter postado (🔴🟠🟡🟢).
- bUnit: depois de Change() num checkbox o elemento re-renderiza —
  re-query o seletor antes do próximo Change (handler id expira).
- #442: finding tem só `line` (sem start/end) — permalink usa `#Lx`
  single; finding file-level (sem linha) leva FileLink sem âncora.
  Backfill não aplicado (runs antigos ficam null — aceitável). âncora
  de localização prefere permalink sobre comment_url; summary_text =
  body postado (review ou comentário único de fallback).
- `dotnet format` já flaggeava drift pré-existente em
  Spec149ModelRouterApiTests.cs (main 693aa88 — não tocado; SDK
  10.0.115 local vs lock/CI).

  `\\uXXXX` escapes.

### Lições SPEC-152

- `AddDbContext` NÃO registra `IDbContextFactory<T>` — registrar
  `AppDbContextFactory` própria sobre `DbContextOptions<T>` singleton.
- EF SQLite: comparação `DateTimeOffset` NÃO traduz — usar mirrors
  `*Ticks` (`CreatedAtTicks`) também em `>=` de range, não só OrderBy.
- `DateTimeOffset.UtcNow.Date` devolve `DateTime` — mismatch de tipo
  quebra tradução EF (usar `new DateTimeOffset(date, TimeSpan.Zero)`).
- Cancel race: status flip com `ExecuteUpdateAsync` condicional
  (`WHERE status=queued`) — nunca ler-e-reengravidar status terminal.
- Shouldly `ShouldAllBe`/`ShouldContain` recebem Expression trees —
  `is` pattern proibido (CS8122); usar `== null`/`!string.IsNullOr`.
- Seed tracked no ctx do teste + writes por outro ctx → `FindAsync`
  devolve cópia stale — `Entry(e).ReloadAsync()` para asserções.
- Método helper `Task(...)` em classe de teste sombreia
  `System.Threading.Tasks.Task` (CS0119) — nomear `MakeTask`.
