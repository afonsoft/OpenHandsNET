## Lições
- SQLite: `OrderBy/Count(DateTimeOffset)` NÃO traduz — usar `*Ticks`
  mirrors (AlertService fontes ordena em memória; cap usa ticks).
- `dotnet ef migrations add` com `--no-build` e dll stale gera
  migration vazia silenciosa — sempre rebuildar antes/verificar Up().
- `///` doc comments NÃO vão dentro de parameter list de record
  (CS1587) — mover pro `<summary>`/`text` do tipo.
- `$$"""` raw strings colidem com `}}` de JSON — usar replace tokens.
- CJK literals em heredoc do agente somem — escrever i18n ja/zh com
  `\\uXXXX` escapes.
