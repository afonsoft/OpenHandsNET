## Lições

- `git log --grep` pega corpo do commit — para mapear SPEC→PR usar
  `--format=%s` (subject only).
- Sed em linhas de tabela com backticks: casar a linha inteira
  (`11c\...`) é mais seguro que regex parcial.
- `dotnet format` num repo sem `.editorconfig`: primeira execução toca
  centenas de arquivos — fazer sempre em commit isolado.
- Actions pinadas por SHA: `gh api repos/actions/{name}/git/refs/tags/v{N}`
  devolve o commit da major tag.
