# i18n (SPEC-46)

JSON localization for the Blazor WASM client — ported from
`afonsoft/open-webui` (MIT).

## Locales

8 dictionaries under `wwwroot/i18n/`: `pt-BR` (default), `en-US`
(complete), `es-ES`, `fr-FR`, `de-DE`, `it-IT`, `ja-JP`, `zh-CN` (main
chrome; the rest falls back). `locales.json` is the manifest (code,
name, dir).

## Fallback and interpolation

`active → en-US → pt-BR → key`. `{{name}}` interpolation via
`L.T(key, ("name", value))`. Dynamic lookups (`attention.kind_{k}`,
`conv.tab_*`, `ide.panel_*`) are covered in the dictionaries.

## Persistence and switching

`ohn.locale` in localStorage + best-effort
`PUT /users/me/preferences {locale}`. `theme.js` (`ohnI18n.setLang`)
applies `lang`/`dir` on `<html>`. `LocalizationService.Changed` in
`MainLayout` re-renders everything without a reload.

## Parity

`I18nParityTests`: manifest ↔ files, en=pt keyset, no alien keys,
identical placeholders across locales. In bUnit tests,
`L10nStub.Register(this)` serves the real JSONs from disk.
