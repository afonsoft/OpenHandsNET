# i18n (SPEC-46)

Localização JSON do client Blazor WASM — port do serviço do
`afonsoft/open-webui` (MIT).

## Locales

8 dicionários em `wwwroot/i18n/`: `pt-BR` (default), `en-US` (completo),
`es-ES`, `fr-FR`, `de-DE`, `it-IT`, `ja-JP`, `zh-CN` (chrome principal;
resto cai no fallback). `locales.json` = manifesto (code, nome, dir).

## Fallback e interpolação

`active → en-US → pt-BR → key`. Interpolação `{{name}}` via
`L.T(key, ("name", value))`. Lookups dinâmicos (`attention.kind_{k}`,
`conv.tab_*`, `ide.panel_*`) estão cobertos nos dicionários.

## Persistência e troca

`ohn.locale` no localStorage + best-effort `PUT /users/me/preferences
{locale}`. `theme.js` (`ohnI18n.setLang`) aplica `lang`/`dir` no
`<html>`. `LocalizationService.Changed` no `MainLayout` re-renderiza
tudo sem reload.

## Parity

`I18nParityTests`: manifesto ↔ arquivos, keyset en=pt, sem chave
alienígena, placeholders idênticos entre locales. Nos testes bUnit,
`L10nStub.Register(this)` serve os JSONs reais do disco.
